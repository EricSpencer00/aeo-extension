AEO Queries

Shows the exact search queries AI assistants run for your prompts.

Where your data lives

Captured prompts and queries are written to this browser's local extension storage and nowhere else. There is no account, no server, and no analytics. Uninstalling the extension deletes everything.

Supported sites

  • Perplexity — every reformulated query it issues, verified against live traffic
  • Claude (claude.ai) — each web_search tool call
  • ChatGPT — search queries from its browsing tool, when signed in
  • Google Gemini and Microsoft Copilot — best effort

Signed-out ChatGPT reports only that it searched; OpenAI does not send the query text to the page, so no extension can recover it there.
