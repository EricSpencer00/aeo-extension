# Quick Start Guide - 3 Minutes to AEO Queries

## Install Locally (2 minutes)

### Step 1: Open Chrome Extensions
- Type `chrome://extensions/` in your address bar and press Enter
- OR Menu (⋮) → More tools → Extensions

### Step 2: Enable Developer Mode
- Toggle **Developer mode** in the top-right corner

### Step 3: Load the Extension
- Click **Load unpacked**
- Navigate to: `~/aeo-extension`
- Click **Select Folder**

**Done!** The extension is now installed.

---

## First Test (1 minute)

### Step 1: Open an AI Chat
- Go to ChatGPT (chatgpt.com), Claude (claude.ai), or Perplexity (perplexity.ai)

### Step 2: Ask a Question
Ask something that requires web search, like:
- "What are the latest trends in web development in 2025?"
- "Best SEO tools for 2025?"
- "How much does cloud hosting cost right now?"

### Step 3: Check Extension
- Click the **AEO Queries** icon in your toolbar
- You should see the search queries the AI made!

2. Open in Excel/Sheets for analysis
3. Use for SEO keyword research

1. See queries from multiple AI services

1. Click **Settings**
2. Choose which AI services to monitor
3. Adjust how many queries to store

## Troubleshooting

**No queries showing up?**
- ✓ Make sure you're on ChatGPT, Claude, or Perplexity
- ✓ Ask a question that requires a web search
- ✓ Refresh the page and try again
- ✓ Check that extension is enabled

**Extension icon not visible?**
- ✓ Click the puzzle icon (🧩) in your toolbar
- ✓ Click the pin icon next to "AEO Queries"
- ✓ It should now stay in your toolbar

**Want to see how it works internally?**
- ✓ Read [DEVELOPMENT.md](DEVELOPMENT.md) for technical details
